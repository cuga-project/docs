# Control Commands

The live CLI reference is [Control Commands](/docs/customization/cli-sdk).

```bash
cuga start demo
cuga start manager
cuga start demo_knowledge
cuga start demo_skills
```

Presets: `demo`, `manager`, `demo_knowledge`, `demo_skills`, `demo_crm`, `demo_supervisor`, `demo_health`, `demo_docs`, `travel_agent`, `registry`, `appworld`.

See also [Manage, publish, and self-host](/docs/customization/manage-publish).
